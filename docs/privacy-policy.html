개인정보처리방침

크롬 확장 프로그램 「은행 모드」 · 최종 수정일 2026-10-27

이 확장 프로그램은 이용자의 어떤 개인정보도 수집·저장(원격)·외부 전송하지 않습니다. 모든 처리는 이용자의 컴퓨터 안에서만 이루어지며, 외부 서버로 보내는 정보는 없습니다.

1. 수집·전송하는 개인정보

없습니다. 이 확장은 이름·연락처·계정·금융정보 등 어떤 개인정보도 수집하지 않고, 외부(인터넷상의 서버, 개발자, 제3자)로 전송하지 않습니다.

이 확장은 같은 컴퓨터에 설치된 「은행 모드」 앱(BankMode.exe) 과만 통신합니다. 이 통신은 네트워크(인터넷)를 거치지 않고 운영체제 내부(Chrome Native Messaging)에서만 이루어집니다.

2. 확장이 접근하는 정보와 사용 방식 (모두 로컬 처리)

정보용도외부 전송
현재 보고 있는 탭의 주소, 그리고 이용자가 접근을 허용한 등록 사이트 탭의 주소 지금 화면이 은행/공공 사이트인지 브라우저 안에서 비교해, 보안 프로그램이 꺼져 있으면 아이콘에 알림 배지를 표시 안 함 (앱에도 보내지 않음)
보안 프로그램 상태 (실행 여부·개수·메모리 사용량) 같은 PC의 「은행 모드」 앱에서 받아 팝업에 표시 안 함
브라우저 저장소 (chrome.storage) 위 상태와 사이트 목록을 이 브라우저에만 임시 저장(표시용) 안 함

기본 등록 사이트는 확장 설치 권한으로 접근하고, 이용자가 추가한 사이트는 팝업에서 해당 도메인 접근을 허용한 뒤에만 접근합니다. 탭 주소는 은행 사이트인지 판단하는 데만 쓰이며, 기록되거나 어디로도 전송되지 않습니다. 방문 기록 전체를 읽지 않습니다(tabs 권한을 사용하지 않음).

3. 외부 서버·제3자·추적

  • 크롬 확장 프로그램은 외부 서버로 통신하지 않습니다.
  • Windows 앱은 새 버전 확인을 위해 GitHub 공개 Releases API에 하루 최대 한 번 요청할 수 있습니다. 이 요청에는 설치 경로, 설정, 보안 프로그램 상태, 사이트 목록 등 로컬 데이터가 포함되지 않습니다. GitHub는 네트워크 요청의 일반 연결 정보를 처리할 수 있습니다.
  • 광고·애널리틱스·추적 도구·쿠키를 사용하지 않습니다.
  • 로컬 데이터를 제3자와 공유하거나 판매하지 않습니다.
  • 확장 프로그램의 통신 상대는 같은 컴퓨터의 「은행 모드」 앱뿐입니다.

4. 요청하는 권한과 이유

권한이유
nativeMessaging같은 PC의 「은행 모드」 앱과 통신(상태 확인, 켜기/끄기)
storage상태·사이트 목록을 브라우저에 임시 저장(표시용)
activeTab팝업을 열 때 지금 보고 있는 탭만 확인(은행 사이트 판단·새로고침)
금융·공공 도메인 host_permissions등록된 은행/공공 사이트에서만 자동으로 알림 배지를 표시

5. 보관 및 삭제

저장되는 정보는 표시용 상태값뿐이며 이용자의 브라우저 저장소에만 있습니다. 확장 프로그램을 삭제하면 이 정보도 함께 사라집니다.

Privacy Policy (English summary)

This extension does not collect, store remotely, or transmit any personal or user data. It has no network requests, no analytics, no ads, no trackers, and no third-party sharing.

The companion Windows app may check GitHub's public Releases API at most once every 24 hours to show an update link. The request does not include local settings, installed security modules, file paths, or a device identifier. GitHub may process ordinary connection metadata such as the request IP address.

The extension communicates only with the companion BankMode application installed on the same computer, over the operating system's Chrome Native Messaging — never over the internet. It uses the current tab's URL (and URLs of listed financial/public sites) only to decide, locally in the browser, whether to show a status badge; these URLs are never stored or sent anywhere. Browser storage is used only to hold display state on this device and is removed when the extension is uninstalled.

Permissions: nativeMessaging (talk to the local app), storage (local display state), activeTab (read the current tab only when the popup is opened), and host permissions limited to Korean financial/public sites (show the badge there). The broad tabs permission is not used.
